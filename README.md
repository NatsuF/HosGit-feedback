# HosGit 反馈中心

鸿蒙 GitHub 客户端 **HosGit** 的建议收集与 Bug 反馈仓库。

## 提交反馈

请点右上角 **Issues → New issue**，按类型选择模板：

| 模板 | 用途 |
|---|---|
| 🐛 Bug 反馈 | 应用闪退、功能异常、显示错误等问题 |
| 💡 功能建议 | 新功能想法或对现有功能的改进建议 |

## 反馈须知

- 提交前请先搜索已有 Issues，避免重复；
- Bug 反馈请尽量附上**应用版本**（「我的 → 关于」页可见）、**设备型号与系统版本**，以及**复现步骤**或截图，能大幅加快定位；
- 建议写清楚你期望的行为与实际行为的差别；
- 反馈均为公开内容，**请勿贴出 GitHub Token、密码等敏感信息**。

## 反馈处理流程

1. **确认**：新反馈一般会在 1~3 天内确认（复现 / 判断类型）；
2. **处理**：确认后的 Bug 按严重程度排队修复，建议经评估后排期；
3. **发布**：修复随新版本上架应用市场，对应 Issue 会在评论区回复版本号后关闭。

> 状态标签说明：`bug` = 已确认缺陷 · `enhancement` = 已采纳建议 · `wontfix` / `duplicate` = 暂不处理或重复。

## 其他渠道

- 使用疑问、闲聊吹水：移步 [Discussions](https://github.com/NatsuF/HosGit-feedback/discussions)；
- 开发动态与更新预告：见开发者小红书主页（应用「关于」页可直达）。
